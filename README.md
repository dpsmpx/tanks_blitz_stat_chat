# Tank Stats Overlay

Оверлей статистики боёв для **World of Tanks Blitz**.

Программа читает урон **с экрана** (плашки «Нанесён урон»), показывает полупрозрачный оверлей поверх игры и ведёт историю по танкам и сессиям. Голосовой ввод не используется.

## Возможности

- Захват выбранной зоны экрана (ROI) и распознавание плашек урона (EasyOCR)
- Отсечение плашек «Урон с вашей помощью»
- Экраны: хаб (MAIN), бой (BATTLE), настройки (SETTINGS)
- Горячие клавиши: **F1** — начало боя, **F2** — победа, **F3** — поражение
- Статистика сессии и по танку: бои, винрейт, средний и лучший урон
- Атомарное сохранение истории; повреждённый файл не роняет программу

## Требования

- Windows 10 / 11
- Python 3.12 или 3.13 (64-bit)
- Игра в **оконном режиме без рамки** (borderless) — иначе захват может быть чёрным
- Для глобальных хоткеев иногда нужен запуск от имени администратора

## Установка

```bash
git clone https://github.com/dpsmpx/tanks_blitz_stat_chat.git
cd tanks_blitz_stat_chat
py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Первый запуск EasyOCR скачивает языковые модели (нужен интернет).

## Запуск

```bash
python tank_overlay.py
```

1. В настройках задайте зону ROI на область плашек урона.
2. Добавьте танки и выберите текущий.
3. **F1** — старт боя, программа считает урон с плашек.
4. **F2** / **F3** — победа / поражение, возврат на главный экран.

## Файлы данных (создаются рядом со скриптом)

| Файл | Назначение |
|------|------------|
| `tank_stat_settings.txt` | ROI, хоткеи, список танков, прозрачность |
| `tank_history.json` | История боёв |
| `tank_stat_glyphs.json` | Служебные шаблоны (совместимость) |

Личные `tank_stat_settings.txt` и `tank_history.json` в git не коммитятся.
